# Online Complaint Registration and Grievance Management System

A full-stack MERN application for citizens to register complaints/grievances with government departments, track resolution status in real time, and enable officers/admins to manage and resolve them efficiently.

## Tech Stack

**Frontend:** React (Vite), Tailwind CSS, React Router, Axios, Socket.IO Client, React Toastify
**Backend:** Node.js, Express.js, MongoDB (Mongoose), JWT Authentication, Socket.IO, Multer, Nodemailer

## Features

- Citizen registration/login with OTP-based email verification
- Role-based access control (User, Officer, Admin)
- Complaint submission with category, department, location, and file attachments
- Real-time status tracking and updates via Socket.IO
- QR-coded complaint receipts (PDF download)
- Voice-to-text complaint description
- Live chat support widget
- Officer/Admin dashboards for complaint assignment and resolution
- Activity logging for auditability
